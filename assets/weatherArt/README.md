# HD weather art

Community Patch 3's HD skies by Fila, from the MTM2 community
(https://forum.mtm2.com/viewtopic.php?p=59830#p59830, download https://mtm2.com/~mtmg/misc/weatherHD.zip).
They are original art, not files of the game.

| File | Replaces |
|---|---|
| `CCLOUDS.PNG` | the Rain sky |
| `CLOUDY2.PNG` | the sky of the older levels (MTM1, CART Precision Racing) |
| `DUSKSKY.PNG` | the Dusk sky |
| `NITESKY.PNG` | the Night and Night Fog sky |

The port uses them with "CP3 HD weather" (Options, Advanced) when the game folder has no `WeatherArt`
folder of its own (`src/worker/weather-art.js`).
